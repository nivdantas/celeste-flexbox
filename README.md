# ⛰︎ Celeste Flexbox

Static webpage project to train flexbox concepts | Pure HTML and CSS

This project is a static webpage inspired by the Celeste game, specifically developed to practice and demonstrate **CSS Flexbox** concepts. The project uses only pure HTML and CSS, without a build step or framework, focusing exclusively on learning and applying flexbox properties.

## Run locally

Open `index.html` in a browser. The page requests Outfit from Google Fonts when online and falls back to a local sans-serif font otherwise.

## 🎯 Learning Objectives

- Master fundamental Flexbox properties
- Practice responsive layouts without using CSS Grid
- Create flexible and adaptive components

## 🚀 Technologies Used

- **HTML5** - Semantic page structure
- **CSS3** - Styling with focus on Flexbox
